# Delivery Delay Prediction (Transport & Logistics Field Project)

Predicts whether a delivery will be **delayed** or **on time** using distance, vehicle type,
traffic level, weather, driver rating and delivery priority.

> **Data note:** the dataset is synthetic (generated by `src/generate_data.py`) so the project
> is self-contained. To use a real Kaggle dataset, replace `data/raw/logistics_delivery_data.csv`
> and adjust the column names in `src/config.py`.

```
│   ├── config.py                # paths, target name, feature lists
│   ├── utils.py                 # load data, train/test split, preprocessing pipeline

│   ├── step2_clean.py           # Step 2: clean
│   ├── step3_visualize.py       # Step 3: charts and insights
│   ├── step4_split.py           # Step 4: 80/20 split
│   ├── step5_models.py          # Step 5: compare 4 models
│   ├── step6_tune.py            # Step 6: GridSearchCV
│   ├── step7_evaluate.py        # Step 7: metrics, confusion matrix, ROC
│   └── run_all.py               # runs steps 1-7
├── models/best_model.joblib     # tuned model
├── reports/
│   ├── model_comparison.csv, best_params.json, final_metrics.json
│   └── figures/                 # all charts (PNG)
├── app/
│   ├── app.py                   # Step 8: Streamlit web app (HTML layout)
│   └── style.css                # custom CSS: gradient hero, result card, gauge, chips
└── .streamlit/config.toml       # light theme and colours
```

## How to run

```bash
pip install -r requirements.txt
python src/run_all.py          # runs the whole pipeline
streamlit run app/app.py       # optional web app
```

Run a single step with, for example, `python src/step2_clean.py`.

## Results

| Model | CV AUC | Test accuracy | Test F1 | Test AUC |
|---|---|---|---|---|
| Logistic Regression | 0.958 | 0.890 | 0.876 | 0.960 |
| Gradient Boosting | 0.958 | 0.897 | 0.885 | 0.963 |
| Random Forest | 0.952 | 0.872 | 0.856 | 0.956 |
| Decision Tree | 0.832 | 0.827 | 0.809 | 0.828 |

**Selected model:** Logistic Regression (highest cross-validated AUC), tuned with GridSearchCV (C = 100).
**Final test performance:** accuracy 89.0%, precision 86.5%, recall 88.5%, F1 0.875, ROC-AUC 0.959.

## Key insights

- Delay rate rises sharply with traffic: Low 14%, Medium 44%, High 79%.
- Bad weather matters: Clear 29%, Rainy 60%, Foggy 65%, Stormy 91%.
- Longer distances and Express priority are also linked to more delays.

## Design decisions

- **No data leakage:** `delivery_time_min` is only known after delivery and defines the target,
  so it is excluded from the model features.
- **Model chosen on cross-validation, not the test set**, so the test set stays unseen.
- **Stratified split** keeps the delayed share the same in train and test.
- **Pipelines** bundle scaling and encoding with the model, so the web app uses the exact same steps.
